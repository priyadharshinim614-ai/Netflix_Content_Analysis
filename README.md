# Netflix Content Analysis Using Python

## Project Overview

This project focuses on analyzing Netflix content using Python and data analysis libraries. The main objective is to explore the Netflix dataset, understand content distribution, identify trends in movie and TV show releases, analyze ratings, and discover the top 10 countries producing Netflix content.

The analysis is performed using **Pandas, Matplotlib, and Python** to extract meaningful insights through data exploration and visualization.

## Objectives

- Understand the structure of the Netflix dataset.
- Perform data exploration and inspection.
- Identify and handle missing values.
- Analyze the top 10 countries with the most Netflix content.
- Visualize Netflix content release trends.
- Explore the distribution of content ratings.
- Draw meaningful conclusions from the analysis.

## Technologies & Libraries Used

- **Python** – Programming language
- **Pandas** – Data manipulation and analysis
- **Matplotlib** – Data visualization
- **Matplotlib.pyplot** – Creating graphs and charts
- **Jupyter Notebook** – Performing data analysis

## Dataset

The project uses the Netflix Movies and TV Shows dataset, which contains information about Netflix titles.

Some important columns include:

- `show_id` – Unique ID of each title
- `type` – Movie or TV Show
- `title` – Name of the content
- `director` – Director of the content
- `cast` – Actors involved
- `country` – Country of production
- `date_added` – Date added to Netflix
- `release_year` – Year of release
- `rating` – Content rating
- `duration` – Movie duration or TV show seasons
- `listed_in` – Genre or category
- `description` – Content description

### 1. Top 10 Countries

Analyzed the top 10 countries producing the most Netflix content using data visualization.

**Objective:** Identify which countries contribute the most movies and TV shows to Netflix.

### 2. Release Trend Analysis

Created a release trend graph using Matplotlib to understand how Netflix content releases have changed over the years.

**Objective:** Identify the growth and distribution of Netflix content across different release years.

### 3. Ratings Analysis

Analyzed the distribution of Netflix content ratings to understand the target audience and content classification.

Objective: Explore which content ratings are most common on Netflix.

## Key Insights

The analysis helps identify:

- Countries with the highest Netflix content production.
- Trends in Netflix content releases over the years.
- Distribution of movies and TV shows.
- Most common content ratings.
- Missing values and dataset structure.
